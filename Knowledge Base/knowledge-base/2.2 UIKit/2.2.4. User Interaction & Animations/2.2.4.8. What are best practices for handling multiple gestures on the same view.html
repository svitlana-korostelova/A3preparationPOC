2.2.4.8. What are best practices for handling multiple gestures on the same view?

Decide which gestures may happen together and which should take priority:

  • Use one recognizer for each distinct gesture. Add a delegate only when you need custom rules.
  • Allow simultaneous recognition only for pairs that should work together, such as pinch and rotation.
  • Use require(toFail:) when one gesture should wait for another, such as a single tap waiting for a double tap.
  • Use gestureRecognizer(_:shouldReceive:) to ignore touches on controls that should handle their own taps.
  • Set cancelsTouchesInView and delaysTouchesBegan deliberately; they affect when the view receives touches.
  • Attach each recognizer to the smallest view that needs it. Prefer UIKit's built-in recognizers over custom touch tracking when they fit.

For example, a delegate can allow pinch and rotation together while returning false for pairs involving a pan recognizer:

func gestureRecognizer(
    _ gestureRecognizer: UIGestureRecognizer,
    shouldRecognizeSimultaneouslyWith other: UIGestureRecognizer
) -> Bool {
    (gestureRecognizer === pinchRecognizer && other === rotationRecognizer) ||
    (gestureRecognizer === rotationRecognizer && other === pinchRecognizer)
}

Follow-up questions

  • How can pinch and rotation run together while pan stays exclusive? Return true only for the pinch/rotation pair in gestureRecognizer(_:shouldRecognizeSimultaneouslyWith:), as shown above. Ensure no other delegate rule allows pan to run with them.
  • How can you find which recognizer handled a missing tap? Inspect recognizers on the hit view and its ancestors. Log their states and check cancelsTouchesInView, delaysTouchesBegan, and delegate decisions.
  • How do SwiftUI gesture modifiers compare? .simultaneousGesture allows gestures to run together; .highPriorityGesture gives a gesture precedence over the view's normal gesture; .gesture adds a gesture at normal priority. These are similar ideas, not exact matches for UIKit's delegate and failure rules.

2.2.4.3. What is BezierPath?

UIBezierPath describes lines, curves, and shapes. It does not draw on screen by itself. In a custom UIView, create the path in draw(_:) — UIKit calls this method when the view needs drawing — then call fill() or stroke() to draw it.

This example draws a filled triangle:

import UIKit

final class TriangleView: UIView {
    override func draw(_ rect: CGRect) {
        let path = UIBezierPath()
        path.move(to: CGPoint(x: rect.midX, y: rect.minY + 20))
        path.addLine(to: CGPoint(x: rect.minX + 20, y: rect.maxY - 20))
        path.addLine(to: CGPoint(x: rect.maxX - 20, y: rect.maxY - 20))
        path.close()

        UIColor.systemBlue.setFill()
        path.fill()
    }
}

Common path methods

  • move(to:) moves the current point without drawing a line.
  • addLine(to:) adds a straight segment.
  • addCurve(to:controlPoint1:controlPoint2:) adds a smooth curve.
  • addArc(withCenter:radius:startAngle:endAngle:clockwise:) adds a circular arc.
  • close() joins the current point back to the start of the shape.
  • fill() fills the path; stroke() draws its outline.

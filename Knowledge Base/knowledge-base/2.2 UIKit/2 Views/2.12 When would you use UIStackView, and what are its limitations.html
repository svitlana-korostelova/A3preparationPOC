2.12. When would you use UIStackView, and what are its limitations?

  • Use it for: simple linear (horizontal/vertical) grouping — forms, toolbars, label+icon rows — where distribution/alignment/spacing replaces dozens of manual `NSLayoutConstraint`s.
  • Toggling visibility: setting `isHidden = true` on an arranged subview removes it from the layout flow (and can be animated) without adding/removing constraints yourself.
  • Nesting: compose complex forms from nested stacks, often inside a `UIScrollView` for dynamic/variable-height content.

Limitations

  • No overlapping/z-order layouts: can't position views on top of each other (e.g., a badge overlay) — falls back to plain Auto Layout or a `ZStack` equivalent.
  • Performance in hot paths: internally it still generates/updates constraints; deeply nested stacks or frequent `isHidden` toggling inside table/collection view cells triggers extra layout passes and can hurt scroll performance — flatten constraints for perf-critical cells.
  • No wrapping: unlike CSS flex-wrap, a stack view won't wrap overflow content to a new line/column; needs a custom `UICollectionViewCompositionalLayout`/flow layout for tag/chip-style UI.
  • Harder debugging: Auto Layout ambiguity/ conflict warnings reference stack view's internally generated constraints, not the ones you wrote, making root-causing harder.
  • Distribution nuances: `.fillEqually` vs `.equalSpacing` vs `.fill` behave differently under content hugging/compression resistance — easy to misconfigure and get unexpected sizing.
let stack = UIStackView(arrangedSubviews: [iconView, titleLabel, spacer])
stack.axis = .horizontal
stack.alignment = .center
stack.distribution = .fill
stack.spacing = 8

// remove from layout without touching constraints, animatable
UIView.animate(withDuration: 0.25) { titleLabel.isHidden = true }

Common Interview Questions

Q: Why avoid deeply nested stack views inside UITableViewCell? A: Each nested stack adds hidden internal constraints, increasing Auto Layout solve time per cell — costly during fast scrolling; prefer flatter, hand-written constraints for hot paths.

Q: How would you build a wrapping tag/chip list? A: `UIStackView` can't wrap; use a custom `UICollectionViewCompositionalLayout` (or custom flow layout), or in SwiftUI a custom `Layout` / wrapping HStack via `GeometryReader`.

Q: How does animating isHidden on an arranged subview work under the hood? A: Wrapping it in `UIView.animate` re-runs the stack's layout — the hidden view is excluded from the arrangement and siblings animate into the freed space, with no manual constraint changes needed.

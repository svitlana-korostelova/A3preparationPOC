How to implement user tap on small and big parent view without misstap? How to change responder?

Typical scenario: a small icon/button sits inside a larger tappable container; taps near the icon's edge should register, while taps clearly belonging to a sibling shouldn't.

  • Enlarge only the tap target, not the visuals: override point(inside:) to expand the view's effective bounds instead of resizing it.
  • Redirect hit-testing from the parent: override hitTest(_:with:) on the container to hand the touch to a specific child even if another view is geometrically on top (e.g. prioritizing a small close button over a large background image).
  • Avoid gesture conflicts instead of fighting via z-order: use require(toFail:) or the delegate methods covered in gesture-recognizer questions.

"Changing responder" usually means forcing first-responder status or forwarding a touch:

// Force first responder change (e.g. text field handoff)
nextTextField.becomeFirstResponder()

// Forward a tap on the large parent to a specific inner view
override func hitTest(_ point: CGPoint, with event: UIEvent?) -> UIView? {
    let hit = super.hitTest(point, with: event)
    return hit == self ? innerTappableView : hit
}

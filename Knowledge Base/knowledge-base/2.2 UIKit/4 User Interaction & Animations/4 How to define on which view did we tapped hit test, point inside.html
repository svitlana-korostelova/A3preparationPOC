How to define on which view did we tapped? hit test, point inside

UIKit resolves the topmost view under a touch via a top-down recursive walk starting at the window:

  1. hitTest(_:with:) is called on a view; it first checks point(inside:with:) and returns nil if the point is outside, or the view is hidden, has alpha < 0.01, or isUserInteractionEnabled == false.
  2. If inside, it recurses into subviews back-to-front (topmost first), converting the point into each subview's coordinate space via convert(_:to:).
  3. The deepest view whose point(inside:) returns true becomes the hit-test view for that touch.

Overriding both lets you customize tappable regions:

override func point(inside point: CGPoint, with event: UIEvent?) -> Bool {
    // expand the tappable area beyond the view's bounds
    bounds.insetBy(dx: -20, dy: -20).contains(point)
}

override func hitTest(_ point: CGPoint, with event: UIEvent?) -> UIView? {
    guard isUserInteractionEnabled, !isHidden, alpha > 0.01 else { return nil }
    return super.hitTest(point, with: event)
}

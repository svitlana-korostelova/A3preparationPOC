2.2.7.1.3. How to implement zoom with 2 fingers?

Two options. Use UIScrollView when the user must zoom and pan (photos, maps, documents). Use UIPinchGestureRecognizer when you need only a simple scale on one view.

Option 1: UIScrollView (recommended)

It gives pinch, pan, bounce, and min/max limits for free.

final class PhotoViewController: UIViewController, UIScrollViewDelegate {
    private let scrollView = UIScrollView()
    private let imageView = UIImageView(image: UIImage(named: "photo"))

    override func viewDidLoad() {
        super.viewDidLoad()
        scrollView.frame = view.bounds
        scrollView.autoresizingMask = [.flexibleWidth, .flexibleHeight]
        scrollView.minimumZoomScale = 1
        scrollView.maximumZoomScale = 4
        scrollView.delegate = self
        view.addSubview(scrollView)

        imageView.contentMode = .scaleAspectFit
        imageView.frame = scrollView.bounds
        scrollView.addSubview(imageView)
        scrollView.contentSize = imageView.bounds.size

        let doubleTap = UITapGestureRecognizer(target: self, action: #selector(toggleZoom(_:)))
        doubleTap.numberOfTapsRequired = 2
        scrollView.addGestureRecognizer(doubleTap)
    }

    func viewForZooming(in scrollView: UIScrollView) -> UIView? { imageView } // the view to scale

    @objc private func toggleZoom(_ gesture: UITapGestureRecognizer) {
        let target: CGFloat = scrollView.zoomScale > 1 ? 1 : 2.5
        scrollView.setZoomScale(target, animated: true)
    }
}

Frames are set once to keep the example short. For rotation support, pin the image view with Auto Layout to contentLayoutGuide and size it with frameLayoutGuide.

Option 2: UIPinchGestureRecognizer

final class ZoomableView: UIView {
    private var startScale: CGFloat = 1

    override init(frame: CGRect) {
        super.init(frame: frame)
        addGestureRecognizer(UIPinchGestureRecognizer(target: self, action: #selector(handlePinch(_:))))
    }

    required init?(coder: NSCoder) { fatalError("init(coder:) has not been implemented") }

    @objc private func handlePinch(_ gesture: UIPinchGestureRecognizer) {
        switch gesture.state {
        case .began:
            startScale = transform.a // current scale
        case .changed:
            let scale = min(max(startScale * gesture.scale, 0.5), 3) // limit 0.5x...3x
            transform = CGAffineTransform(scaleX: scale, y: scale)
        default:
            break
        }
    }
}
  1. Detect: UIPinchGestureRecognizer reports scale (relative to the gesture start) and velocity.
  2. Apply: CGAffineTransform(scaleX:y:) scales the view around its centre.
  3. Keep state: save the scale at .began, because gesture.scale starts from 1 on every new pinch.

Follow-up questions

  • Why do I need startScale? Each pinch starts with gesture.scale == 1. Without a saved start value, the view jumps back to 1x on the next pinch.
  • Why does my zoom not follow my fingers? A transform scales around the view's centre. To zoom at the pinch point, set the layer's anchorPoint to the pinch location in .began and fix position so the view does not jump. UIScrollView does this for you.
  • How do I add rotation too? Add a UIRotationGestureRecognizer and allow both with gestureRecognizer(_:shouldRecognizeSimultaneouslyWith:) returning true. Then transform.a is no longer the pure scale.
  • Why is the scroll view image blurry when zoomed? A transform stretches the bitmap. For sharp zoom, load a bigger image or use CATiledLayer for very large images.
  • How is pinch zoom done in SwiftUI? MagnifyGesture (iOS 17; MagnificationGesture before) with .scaleEffect, plus a saved base scale.

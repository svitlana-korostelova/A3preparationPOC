2.2.7.1.2. How to round only two angles in view?

Use CALayer.maskedCorners (iOS 11+). It works with cornerRadius and picks which corners get the radius.

// Top corners only
view.layer.cornerRadius = 16
view.layer.maskedCorners = [.layerMinXMinYCorner, .layerMaxXMinYCorner]

// Bottom corners only
view.layer.maskedCorners = [.layerMinXMaxYCorner, .layerMaxXMaxYCorner]

// Left corners only
view.layer.maskedCorners = [.layerMinXMinYCorner, .layerMinXMaxYCorner]

view.layer.cornerCurve = .continuous // smooth "squircle" like system UI
  • cornerRadius sets the size. maskedCorners selects the corners. In UIKit, MinY is the top and MinX is the left (flipped coordinates).
  • maskedCorners only changes the shape of the layer's own background and border. To also clip subviews (for example an image), set clipsToBounds = true (layer.masksToBounds).

Older way: path + shape mask

Use it if you must support iOS 10 or need a custom shape. The mask path depends on the size, so update it in layoutSubviews.

final class RoundedTopView: UIView {
    private let maskLayer = CAShapeLayer()

    override func layoutSubviews() {
        super.layoutSubviews()
        maskLayer.path = UIBezierPath(roundedRect: bounds,
                                      byRoundingCorners: [.topLeft, .topRight],
                                      cornerRadii: CGSize(width: 16, height: 16)).cgPath
        layer.mask = maskLayer
    }
}

Common use cases

  • Bottom sheets: round the top corners.
  • Grouped table sections: round the top corners of the first cell and the bottom corners of the last cell.
  • Cards or chat bubbles: round different corners for a "tail" effect.

Follow-up questions

  • Why is my shadow cut when I round corners and clip? masksToBounds clips everything outside the bounds, including the layer's own shadow. Use two views: an outer view with the shadow (set shadowPath) and an inner view with the corners and clipping.
  • Why prefer maskedCorners over a mask layer? It needs no path updates on resize, and it avoids an extra mask layer that can cause off-screen rendering.
  • Can cornerRadius alone clip subviews? No. It only rounds the layer's own background and border. Clipping needs masksToBounds (which can trigger off-screen rendering when combined with other effects).

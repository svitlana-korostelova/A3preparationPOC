2.2.7.1.1. How will you implement custom animation or do split view or do non-standard navigation bar?

Rule: use the system component first and customize it through public API. Build from scratch only if the design cannot be done any other way.

1. Custom animation

  • Property change on a view: UIView.animate or UIViewPropertyAnimator (pause, reverse, scrub).
  • Layer or shape: CABasicAnimation / CAKeyframeAnimation on a CALayer (see 2.2.4.2).
  • Between screens: set transitioningDelegate (modal) or the navigation controller's delegate (push), and return an object that conforms to UIViewControllerAnimatedTransitioning. Add UIPercentDrivenInteractiveTransition for gesture-driven back swipe (see 2.2.1.4).
final class FadeScaleAnimator: NSObject, UIViewControllerAnimatedTransitioning {
    func transitionDuration(using ctx: UIViewControllerContextTransitioning?) -> TimeInterval { 0.35 }

    func animateTransition(using ctx: UIViewControllerContextTransitioning) {
        guard let toView = ctx.view(forKey: .to) else { return }
        ctx.containerView.addSubview(toView)
        toView.alpha = 0
        toView.transform = CGAffineTransform(scaleX: 0.9, y: 0.9)

        UIView.animate(withDuration: transitionDuration(using: ctx), animations: {
            toView.alpha = 1
            toView.transform = .identity
        }, completion: { _ in
            ctx.completeTransition(!ctx.transitionWasCancelled) // always call, or the UI freezes
        })
    }
}

2. Split view

  • Use UISplitViewController. It collapses to one column on iPhone and compact width automatically.
  • Since iOS 14 use the column API: UISplitViewController(style: .doubleColumn) or .tripleColumn, then setViewController(_:for:) for .primary, .secondary, .compact.
  • Do not push the detail yourself. Call show(.secondary) and let the controller decide for each size class.
  • Control the collapsed start screen with splitViewController(_:topColumnForCollapsingToProposedTopColumn:), or the user sees an empty detail on iPhone.
  • If the design is far from the system pattern, build your own container with child view controllers (see 2.2.1.6).
let split = UISplitViewController(style: .doubleColumn)
split.setViewController(UINavigationController(rootViewController: ListViewController()), for: .primary)
split.setViewController(UINavigationController(rootViewController: DetailViewController()), for: .secondary)
split.setViewController(UINavigationController(rootViewController: ListViewController()), for: .compact)
split.preferredDisplayMode = .oneBesideSecondary
split.preferredSplitBehavior = .tile

3. Non-standard navigation bar

  • Style only (colour, font, blur, no shadow): UINavigationBarAppearance with standardAppearance, scrollEdgeAppearance, compactAppearance. Set all of them, or the bar looks different at the top of a scroll view.
  • Custom content: navigationItem.titleView, leftBarButtonItems, rightBarButtonItems with customView.
  • Fully custom bar: hide the system bar (setNavigationBarHidden(true, animated:)) and add your own view. You lose the back swipe. Restore it as shown below.
  • Custom bar class: UINavigationController(navigationBarClass:toolbarClass:).
let appearance = UINavigationBarAppearance()
appearance.configureWithTransparentBackground()
appearance.titleTextAttributes = [.foregroundColor: UIColor.label]
navigationController?.navigationBar.standardAppearance = appearance
navigationController?.navigationBar.scrollEdgeAppearance = appearance
navigationController?.navigationBar.compactAppearance = appearance

Keep the back swipe when the system bar is hidden:

final class AppNavigationController: UINavigationController, UIGestureRecognizerDelegate {
    override func viewDidLoad() {
        super.viewDidLoad()
        setNavigationBarHidden(true, animated: false)
        interactivePopGestureRecognizer?.delegate = self
    }

    func gestureRecognizerShouldBegin(_ gestureRecognizer: UIGestureRecognizer) -> Bool {
        viewControllers.count > 1 // on the root screen the swipe would freeze navigation
    }
}

Follow-up questions

  • Why does the back swipe stop working with a custom bar or custom back button? The system pop gesture is tied to the standard bar and its delegate. Hiding the bar or replacing leftBarButtonItem disables it. Fix it with the delegate above.
  • Why do I need completeTransition? UIKit waits for it to finish the transition. Without it, the screen is stuck and gets no touches.
  • Why does the nav bar look different when I scroll? scrollEdgeAppearance is used at the top of the scroll view, standardAppearance after scrolling. Set both (and compactAppearance) to get the same look at every scroll position.
  • Custom bar view or system bar: which is better? System bar: Dynamic Type, large titles, accessibility, and iOS updates come free. Custom bar gives full design freedom but you own all of it. Prefer appearance API unless the design needs more.

2.2.7.6. How to implement pull to refresh?

Use UIRefreshControl (iOS 6+). Since iOS 10 every UIScrollView (table, collection, plain scroll view) has a refreshControl property. UIKit handles the pull gesture, the spinner and the bounce-back for you.

Basic example (UITableView + async/await)

final class FeedViewController: UITableViewController {
    private var items: [String] = []
    private var refreshTask: Task<Void, Never>?

    override func viewDidLoad() {
        super.viewDidLoad()
        tableView.refreshControl = UIRefreshControl()
        tableView.refreshControl?.addTarget(self,
                                            action: #selector(handleRefresh),
                                            for: .valueChanged)
    }

    @objc private func handleRefresh() {
        refreshTask?.cancel()
        refreshTask = Task { @MainActor in
            defer { tableView.refreshControl?.endRefreshing() }
            do {
                items = try await api.loadItems()
                tableView.reloadData()
            } catch {
                // show an error, keep the old data
            }
        }
    }

    override func tableView(_ tableView: UITableView, numberOfRowsInSection section: Int) -> Int { items.count }

    override func tableView(_ tableView: UITableView, cellForRowAt indexPath: IndexPath) -> UITableViewCell {
        let cell = tableView.dequeueReusableCell(withIdentifier: "Cell", for: indexPath)
        cell.textLabel?.text = items[indexPath.row]
        return cell
    }
}
  • Listen to .valueChanged. It fires when the user pulls far enough and releases.
  • Always call endRefreshing(), also on error. Use defer.
  • Update UI on the main thread. @MainActor on the Task does this.

Start refresh from code

beginRefreshing() only starts the spinner. It does not scroll the content and does not send .valueChanged. Scroll manually and call your load method.

func refreshProgrammatically() {
    guard let control = tableView.refreshControl else { return }
    control.beginRefreshing()
    tableView.setContentOffset(CGPoint(x: 0, y: -control.frame.height - tableView.adjustedContentInset.top),
                               animated: true)
    handleRefresh()
}

Combine version

private var cancellables = Set<AnyCancellable>()

refreshControl.publisher(for: .valueChanged)    // custom publisher or UIControl extension
    .flatMap { _ in api.itemsPublisher() }
    .receive(on: DispatchQueue.main)
    .sink { [weak self] items in
        self?.items = items
        self?.tableView.reloadData()
        self?.tableView.refreshControl?.endRefreshing()
    }
    .store(in: &cancellables)

SwiftUI

Use the .refreshable modifier (iOS 15+). The spinner stays visible until the async closure returns, so there is no endRefreshing().

struct FeedView: View {
    @State private var items: [String] = []

    var body: some View {
        List(items, id: \.self) { Text($0) }
            .refreshable {
                items = (try? await api.loadItems()) ?? items
            }
    }
}

Custom pull to refresh

If the design needs a custom animation, there are two common ways:

  • Keep UIRefreshControl as a hidden host. Hide its default spinner and add your own view as a subview. Update it in scrollViewDidScroll using contentOffset.y.
  • Do it from scratch: put a header view above the content and read contentOffset.y in scrollViewDidScroll. When the offset passes a threshold and the user releases (scrollViewDidEndDragging), start loading and animate contentInset.top to keep the header visible. Reset the inset when done.

Follow-up questions

  • Why does the spinner jump or the layout glitch? Usually endRefreshing() is called while the user is still dragging, or the table is reloaded during the scroll. Wait until dragging ends, then reload.
  • Why is the refresh control hidden in a large-title navigation bar? The scroll view must be under the navigation bar and use the right contentInsetAdjustmentBehavior. Use UITableViewController or pin the table to the view edges.
  • How do you avoid double requests? Cancel the previous task before starting a new one (as in the example), or ignore the call while a request is running.
  • How do you add pull to refresh to a plain UIScrollView? Same way: scrollView.refreshControl = UIRefreshControl(). Set alwaysBounceVertical = true if the content is shorter than the screen.

3.3. Strong, weak, unowned

Short answer

These are the three ways a variable can point to a class instance. Strong keeps the object alive. Weak and unowned do not. The difference between them is what happens after the object dies: weak becomes nil, unowned traps (crashes).

Only class instances (AnyObject) can be held weakly or unowned. Structs and enums cannot.

Strong

Every reference is strong unless you say otherwise. The object stays alive while at least one strong reference exists.

var a: User? = User("Alice")   // count = 1
var b = a                         // count = 2
a = nil                             // count = 1, still alive
b = nil                             // count = 0, deinit

Weak

Does not keep the object alive. Becomes nil when the object dies, so it is always safe to check.

  • Must be weak var, never weak let (the runtime has to be able to set it to nil).
  • Must be Optional.
protocol NetworkDelegate: AnyObject { func didReceive(data: Data) }

class NetworkClient {
    weak var delegate: (any NetworkDelegate)?   // the classic weak use
}

class Node {
    weak var parent: Node?    // child → parent: weak
    var children: [Node] = []  // parent → child: strong (parent owns children)
}

Unowned

Does not keep the object alive, is not optional, and assumes the object is still alive. Use it only when the holder can never outlive the object it points to. If the object is gone, access traps with a clear error.

class Customer {
    var card: CreditCard?
}
class CreditCard {
    unowned let owner: Customer   // a card cannot exist without its customer
    init(owner: Customer) { self.owner = owner }
}

Closure capture lists

Closures capture self strongly by default. Use a capture list to choose the reference type.

class ViewModel {
    var onUpdate: (() -> Void)?

    func setup() {
        onUpdate = { self.refresh() }            // ❌ cycle: self → closure → self
        onUpdate = { [weak self] in self?.refresh() } // ✅ safe if self may be gone
        onUpdate = { [unowned self] in self.refresh() } // ✅ only if self always outlives the closure
    }
    func refresh() {}
}

When you capture [weak self] and need self several times, promote it once. This also stops it from dying in the middle of the closure:

onUpdate = { [weak self] in
    guard let self else { return }   // strong for the rest of this scope
    self.refresh()
    self.updateUI()
}

If unsure, use [weak self]. A crash from unowned is worse than a skipped callback.

3.2. Reference counting

How it works

Every heap-allocated class instance carries a reference count in its object header (the first word of the allocation). ARC tracks how many variables, properties, or closures currently hold a strong reference to that instance.

  • retain — count + 1. Happens when you assign the reference to a new variable or pass it into a function.
  • release — count − 1. Happens when a variable goes out of scope or is reassigned.
  • When the count reaches 0 → deinit is called, then the memory is returned to the heap allocator.

Object header layout (simplified)

// Conceptual — Swift object header (64-bit)
// [isa pointer (8 bytes)] [refcount word (8 bytes)]
// The refcount word encodes strong count, unowned count, and flags.
// A "side table" is allocated lazily for weak references.

Seeing deinit fire

class Dog {
    let name: String
    init(_ name: String) { self.name = name; print("init \(name)") }
    deinit              { print("deinit \(name)") }
}

func example() {
    var a: Dog? = Dog("Rex")  // refcount = 1  → prints "init Rex"
    var b = a                   // refcount = 2
    a = nil                    // refcount = 1  (b still holds it)
    b = nil                    // refcount = 0  → prints "deinit Rex"
}

Retain/release are atomic

Because multiple threads can simultaneously hold and release references to the same object, the increment/decrement of the reference count must be thread-safe. ARC uses atomic compare-and-swap operations. This is why excessive retain/release traffic on hot paths has measurable overhead — each atomic op involves a memory barrier.

Tip: prefer value types (struct) for data that doesn't need shared identity; they have zero ARC overhead.

isKnownUniquelyReferenced

isKnownUniquelyReferenced(&ref) returns true if no other variable holds a strong reference to the object at this moment. This is the mechanism that powers Copy-on-Write for standard library types like Array and Dictionary.

final class Buffer {
    var data: [Int]
    init(_ d: [Int]) { data = d }
}

struct MyArray {
    private var buffer = Buffer([])

    mutating func append(_ value: Int) {
        if !isKnownUniquelyReferenced(&buffer) {
            buffer = Buffer(buffer.data)  // copy before mutating
        }
        buffer.data.append(value)
    }
}

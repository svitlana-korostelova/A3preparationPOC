3.8. Stack

Mechanics

The stack is a contiguous block of memory allocated per thread at thread creation. It grows downward in virtual address space (on ARM64 and x86-64). The CPU maintains a stack pointer (SP) register that points to the current top of the stack.

  • Push (function call): SP decrements by the size of the stack frame. The frame holds the return address, saved registers, function parameters, and local variables.
  • Pop (function return): SP increments back — the frame disappears instantly. No free(), no ARC, no bookkeeping.

Because the stack is thread-local, no synchronization is ever needed to access it. That makes stack allocation effectively free compared to heap.

Stack overflow

When a function call exceeds the remaining stack space, the process crashes with EXC_BAD_ACCESS on the guard page placed just below the stack. The most common cause is unbounded recursion.

// Stack overflow via unbounded recursion
func infinite(_ n: Int) -> Int {
    return infinite(n + 1)   // no base case → EXC_BAD_ACCESS
}

// Safe: tail-call optimisation (TCO) — Swift does NOT guarantee TCO,
// but iterative rewrites are always safe.
func factorial(_ n: Int) -> Int {
    var result = 1
    var i = n
    while i > 1 { result *= i; i -= 1 }
    return result
}

What lives on the stack

  • Local struct, enum, and tuple values (when they fit and don't escape)
  • Primitive types: Int, Double, Bool, UInt8, etc.
  • Function parameters and return values (passed in registers or on the stack frame)
  • Pointers to heap objects (the pointer itself is on the stack; the object is on the heap)
  • Saved callee registers and the return address
struct Vector3 {
    var x, y, z: Double   // 24 bytes total
}

func dot(_ a: Vector3, _ b: Vector3) -> Double {
    // Both a and b are stack copies — 24 bytes each in the frame.
    // No heap allocation, no ARC, no lock.
    return a.x * b.x + a.y * b.y + a.z * b.z
}   // Frame popped on return — a and b gone instantly

Recursion depth in practice

With 512 KB on a background thread and a typical frame of ~200–500 bytes, you get roughly 1,000–2,500 recursive calls before overflow. For deep recursion (tree traversal, parsing), convert to an explicit stack ([Element]) to move the depth onto the heap.

// Iterative tree traversal — depth lives on the heap (the `stack` array),
// not on the call stack.
func dfs(root: TreeNode?) {
    var stack: [TreeNode] = []
    if let r = root { stack.append(r) }
    while let node = stack.popLast() {
        // process node
        if let right = node.right { stack.append(right) }
        if let left  = node.left  { stack.append(left)  }
    }
}

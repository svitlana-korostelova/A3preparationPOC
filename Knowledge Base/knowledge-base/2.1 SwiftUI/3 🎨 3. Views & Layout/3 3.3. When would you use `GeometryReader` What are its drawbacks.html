**3.3. When would you use `GeometryReader`? What are its drawbacks?**

  • You use GeometryReader in SwiftUI when you need access to the size and position of a view’s container. It’s helpful for building layouts that adapt to different screen sizes, custom alignments, or when you need to position elements based on dynamic geometry.

    Drawbacks of GeometryReader:

    Issue Description
    Takes full space GeometryReader expands to fill all available space By default, GeometryReader takes all available space, which can lead to unexpected layouts if not constrained.
    Performance Overuse causes unnecessary re-renders triggers extra layout passes.
    Alignment issues Child views align to top-leading by default
    Avoid overuse Use only when built-in layout tools aren't enough

    Most Common Use Cases

    3.3.1. 📐 Proportional/Responsive Sizing

    ```swift GeometryReader { geometry in HStack { Rectangle() .fill(.blue) .frame(width: geometry.size.width * 0.6) // 60% of screen

        Rectangle()
        .fill(.red)
        .frame(width: geometry.size.width * 0.4) // 40% of screen
}

    } ```

    3.3.2. 📍 Getting View Position (Frame)

    swift GeometryReader { geometry in Text("Hello") .onAppear { let frame = geometry.frame(in: .global) print("X: \(frame.origin.x), Y: \(frame.origin.y)") } }

    3.3.3. 🎢 Scroll-Based Animations

    ```swift ScrollView { ForEach(items) { item in GeometryReader { geometry in let offset = geometry.frame(in: .global).minY

            CardView(item: item)
            .scaleEffect(calculateScale(offset))
            .opacity(calculateOpacity(offset))
    }
}

    } ```

    3.3.4. 📱 Adaptive Layouts (Device Size)

    swift GeometryReader { geometry in if geometry.size.width > 600 { // iPad layout HStack { SidebarView() ContentView() } } else { // iPhone layout VStack { ContentView() } } }

    5. 🎨 Custom Drawing / Shapes

    ```swift GeometryReader { geometry in Path { path in let width = geometry.size.width let height = geometry.size.height

        path.move(to: CGPoint(x: 0, y: height))
    path.addLine(to: CGPoint(x: width / 2, y: 0))
    path.addLine(to: CGPoint(x: width, y: height))
}
.fill(.blue)

    } ```

    6. 📊 Dynamic Progress Bars / Charts

    ```swift struct ProgressBarView: View {

    var progress: CGFloat  // Value between 0.0 and 1.0

var body: some View {
    GeometryReader { geometry in
        ZStack(alignment: .leading) {

            // Background Track
            Rectangle()
                .fill(.gray.opacity(0.3))

            // Filled Progress
            Rectangle()
                .fill(.blue)
                .frame(width: geometry.size.width * progress) // 👈 progress used here
        }
    }
    .frame(height: 20)
    .cornerRadius(10)
}

    } ```

    7. 🔄 Parallax Effects

    ```swift ScrollView { GeometryReader { geometry in let offset = geometry.frame(in: .global).minY

        Image("banner")
        .resizable()
        .scaledToFill()
        .offset(y: offset > 0 ? -offset * 0.5 : 0) // Parallax
}
.frame(height: 300)

    } ```

    8. 📌 Anchor Preferences (View Position Tracking)

    Tool tip - find position of some UI element and e.g. add onboarding overlay

    Drop down menu

    ```swift struct ContentView: View { @State private var buttonFrame: CGRect = .zero

    var body: some View {
    Button("Click Me") { }
        .background(
            GeometryReader { geometry in
                Color.clear

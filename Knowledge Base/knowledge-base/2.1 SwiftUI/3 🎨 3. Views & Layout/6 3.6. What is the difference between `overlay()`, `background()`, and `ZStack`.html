**3.6. What is the difference between `overlay()`, `background()`, and `ZStack`?**

  • overlay() adds a view on top of the current view. Useful for badges, highlights, or custom decorations.

    jsx Text("Hello") .overlay( Circle().stroke(Color.red, lineWidth: 2) )

    background() adds a view behind the current view. Used for backgrounds, shadows, or custom shapes.

    jsx Text("Hello") .background( Rectangle().fill(Color.yellow) )

    ZStack Combines multiple views, stacking them on top of each other in the order they’re declared. Used for complex layouts where you need to layer several views, not just one overlay or background.

    jsx ZStack { Rectangle().fill(Color.yellow) Text("Hello") Circle().stroke(Color.red, lineWidth: 2) }

    Modifier Layer Position Use Case Multiple Layers?
    overlay() Above the view Badges, highlights No (single view)
    background() Below the view Backgrounds, shadows No (single view)
    ZStack Multiple, flexible Complex layered layouts Yes

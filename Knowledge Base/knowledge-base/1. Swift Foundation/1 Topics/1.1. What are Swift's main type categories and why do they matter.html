1.1. What are Swift's main type categories and why do they matter?

Swift is strongly and statically typed. Common value types include struct, enum, tuples, and primitive types; reference types include class and closures. The compiler catches incompatible assignments early, while type inference keeps declarations concise. Prefer immutable let values and model data with value types unless identity, inheritance, or shared mutable state is required.

struct User {
    let id: UUID
    var name: String
}

let user = User(id: UUID(), name: "Taylor")

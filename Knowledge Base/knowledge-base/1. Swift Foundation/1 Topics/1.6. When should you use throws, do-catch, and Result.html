1.6. When should you use throws, do-catch, and Result?

Use throws for synchronous operations whose failure should be handled by the caller. Use do-catch to recover, translate, or report errors. Result<Success, Failure> is useful when a success or failure value must be stored or passed through callbacks. Define focused error types and do not swallow errors with empty catches.

enum ParseError: Error {
    case invalidInput
}

func parse(_ value: String) throws -> Int {
    guard let number = Int(value) else { throw ParseError.invalidInput }
    return number
}

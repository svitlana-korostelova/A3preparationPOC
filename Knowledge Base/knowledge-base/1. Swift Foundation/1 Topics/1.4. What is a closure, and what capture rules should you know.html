1.4. What is a closure, and what capture rules should you know?

A closure is a self-contained function value that can capture constants and variables from its surrounding scope. Captured reference types are normally retained strongly, which can create cycles when a closure is stored by the captured object. Use a capture list such as [weak self] when the closure should not keep an owner alive.

final class Loader {
    var onComplete: (() -> Void)?

    func finish() {
        onComplete?()
    }
}

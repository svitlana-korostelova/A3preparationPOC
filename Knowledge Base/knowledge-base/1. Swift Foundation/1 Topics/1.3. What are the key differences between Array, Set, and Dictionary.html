1.3. What are the key differences between Array, Set, and Dictionary?

Array preserves order and permits duplicates. Set stores unique hashable elements and is useful for membership checks. Dictionary maps unique hashable keys to optional values. Arrays provide indexed access, while sets and dictionaries generally provide near-constant-time lookup.

let tags = Set(["swift", "ios", "swift"])
var scores = ["swift": 10]
scores["ios"] = 8

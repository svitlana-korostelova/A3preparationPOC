1.2. How should you unwrap and work with optionals safely?

An optional represents either a value or nil. Use optional binding when the value is needed in a scope, guard when failure should exit early, and nil-coalescing when a default is appropriate. Avoid force-unwrapping unless an invariant is guaranteed and documented.

func displayName(for user: User?) -> String {
    guard let user else { return "Anonymous" }
    return user.name
}

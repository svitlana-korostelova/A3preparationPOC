1.7. When should you choose a struct versus a class?

A structure is copied by value, making independent state and thread-safe composition easier. A class has identity and reference semantics, so multiple variables can observe the same instance; it is appropriate for shared identity, inheritance, or lifecycle-managed resources. Swift collections use copy-on-write, so value semantics do not necessarily imply an immediate deep copy.

struct Settings {
    var theme = "light"
}

var first = Settings()
var second = first
second.theme = "dark"
// first.theme remains "light"

1.5. How do protocols and generics provide reusable Swift designs?

A protocol defines capabilities without prescribing a concrete type. Generics preserve type information while allowing an algorithm to work with many types. Together they enable composition and dependency inversion: depend on a protocol, constrain generic code only as much as necessary, and use protocol extensions for shared default behavior.

protocol IdentifiableValue {
    associatedtype ID: Hashable
    var id: ID { get }
}

func first<T>(_ values: [T]) -> T? {
    values.first
}
